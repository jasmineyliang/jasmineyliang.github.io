## Preservation notes

- Original spelling, capitalization, duplicates, and citation wording have been retained.
- The Donut Shop link contains malformed Markdown inside its HTML URL. It is recorded rather than silently repaired.
- Some image URLs contain spaces and some badge labels have underscores converted to spaces for readability. Exact source attribute values remain in the HTML snapshot.
- Link destinations have been recorded, not individually checked for availability. Linked repositories, slide decks, certificates, classrooms, and full papers have not been downloaded or inventoried internally.
- The homepage biography still describes the Notre Dame role. The newer Meta role, LinkedIn biography, SeatSwap project, and Simulation / Perception / Production framing supplied in this conversation are additional material for the future site; they are not substituted into this historical inventory.
- Five papers means all five shown on this homepage, not a claim that these are all publications in the author's career.

## Redesign preservation rule

Use this inventory as the content baseline. For each entry, record its eventual destination before reorganizing the portfolio. Featured selections must not silently remove the complete project, publication, awards, or service collections.
